# Правила для работы в репозитории mavzu

Mavzu — классификатор тем узбекских новостей (15 классов). Эти правила действуют во всех сессиях.

- Никогда не выдумывай метрики. В README только числа из реальных прогонов, иначе оставляй TBD.
- После каждого шага: `make test`, `make lint`, маленький git-коммит на английском.
- `data/` и `models/` не коммитить, `reports/` коммитить.
- Если ошибку не удаётся исправить за 2–3 попытки, остановись и опиши её.
- Каждая задача должна укладываться в ~15 минут.
